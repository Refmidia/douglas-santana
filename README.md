# Douglas Santos — Link na Bio

Landing page premium / radical para **Douglas Santos** (`@douglashsantana`).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Rodar

```bash
cd douglas-santana
npm install
npm run dev
```

Abre [http://localhost:3002](http://localhost:3002).

## Editar dados

Tudo em `src/data/profile.ts`.
